안전한 비밀번호 생성기 개인정보 처리방침

시행일 및 최종 업데이트: 2026년 10월 28일

안전한 비밀번호 생성기는 비밀번호 생성·변형 및 랜덤 닉네임 생성 기능을 제공하는 Chrome 확장 프로그램입니다. 기존 비밀번호 입력값은 확장 프로그램이 열려 있는 동안 브라우저 내부에서 일시적으로 처리하며, 개발자 서버로 전송하거나 별도의 영구 저장소에 저장하지 않습니다.

1. 처리하는 정보와 목적

사용자가 입력한 기존 비밀번호: 사용자가 기존 비밀번호 변형 기능을 선택하고 직접 입력한 경우, 지정한 일부 문자를 유지하면서 새 비밀번호를 만들기 위해 해당 입력값을 브라우저 내부에서 일시적으로 처리합니다.

생성된 비밀번호와 안전도 결과: 비밀번호 생성 및 안전도 안내 기능을 제공하기 위해 확장 프로그램 화면에서 계산하고 표시합니다.

랜덤 닉네임: 사용자가 닉네임 생성 기능을 실행할 때 확장 프로그램에 포함된 단어 목록을 이용해 생성합니다.

2. 저장 및 전송

이 확장 프로그램은 입력한 기존 비밀번호, 생성된 비밀번호, 닉네임을 개발자 서버나 제3자 서버로 전송하지 않습니다. 해당 값을 쿠키, 로컬 스토리지 또는 원격 데이터베이스에 영구 저장하지 않습니다. 기존 비밀번호 입력란은 변형 처리 시 성공 또는 실패와 관계없이 비워집니다. 생성 결과는 팝업 화면에 표시되는 동안 메모리에서 유지될 수 있습니다.

3. 클립보드 사용

사용자가 비밀번호 또는 닉네임의 복사 버튼을 직접 누르면 해당 결과를 기기의 클립보드에 기록합니다. 복사된 값은 사용자의 기기 클립보드에 남을 수 있으며, 클립보드의 내용은 사용자가 다른 내용을 복사하거나 기기 설정에서 지울 때까지 유지될 수 있습니다.

4. 공유 및 광고

이 확장 프로그램은 위에서 설명한 입력값이나 생성 결과를 개발자 또는 제3자와 공유·판매하지 않으며, 광고 타기팅이나 사용자 프로파일링에 사용하지 않습니다. 분석 도구, 광고 SDK 또는 원격 코드 로딩 기능을 포함하지 않습니다.

5. 보관 기간 및 삭제

기존 비밀번호 입력값은 변형을 위한 일시적 처리에만 사용하고 입력란에서 삭제합니다. 비밀번호와 닉네임 생성 결과는 별도의 영구 저장소에 저장하지 않습니다. 사용자가 복사한 결과는 기기 클립보드의 동작에 따라 별도로 남을 수 있습니다.

6. 보안

비밀번호 생성은 브라우저의 Web Crypto API를 이용한 난수 생성 기능을 사용합니다. 사용자는 생성된 비밀번호를 안전한 비밀번호 관리자 등에 보관하고, 서비스마다 서로 다른 비밀번호를 사용하는 것이 좋습니다.

7. 정책 준수 및 변경

이 확장 프로그램은 데이터를 명시된 기능 제공 목적으로만 처리하며, 데이터 처리 방식이 변경되면 본 방침을 업데이트하고 필요한 경우 확장 프로그램 내에서 변경 내용을 안내합니다.

Safe Password Generator Privacy Policy

Effective and last updated: October 28, 2026

Safe Password Generator is a Chrome extension for generating and transforming passwords and generating random nicknames. When a user enters an existing password, the extension processes it temporarily within the browser. It does not send the entered password to the developer's server or store it in persistent storage.

1. Information handled and purposes

Existing password: If a user chooses the password transformation feature and enters an existing password, the extension temporarily processes the value locally to create a new password while preserving the requested number of starting characters.

Generated passwords and strength results: These are calculated and displayed in the extension interface to provide password generation and strength guidance.

Random nicknames: Nicknames are generated from word lists included in the extension when the user activates the nickname feature.

2. Storage and transmission

The extension does not transmit entered passwords, generated passwords, or nicknames to the developer or third-party servers. It does not persist these values in cookies, local storage, or a remote database. The existing-password input field is cleared after a transformation attempt, whether it succeeds or fails. Generated results may remain in memory while the popup is open.

3. Clipboard

When a user clicks a copy button, the selected password or nickname is written to the device clipboard. A copied value may remain on the device clipboard until the user copies other content or clears the clipboard through device settings.

4. Sharing and advertising

The extension does not share or sell the values described above to the developer or third parties, and does not use them for ad targeting or user profiling. It does not include analytics tools, advertising SDKs, or remote-code loading.

5. Retention and deletion

The existing password is used only for temporary transformation and is cleared from the input field. Password and nickname results are not stored in persistent storage. Results copied by the user may remain on the device clipboard according to the clipboard's behavior.

6. Security

Password generation uses the browser's Web Crypto API for random number generation. Users should store generated passwords in a trusted password manager and use unique passwords for different services.

7. Policy compliance and changes

The extension handles data only to provide its stated features. If data practices change, this policy will be updated and, where appropriate, the change will be disclosed in the extension.
